# Virtual meeting #2 recap

June 4, 2025

Please note most topics have an associated github issue. You are encouraged to post comments there as this is a great place for transparent discussion on these Argo-related topics! I have done my best to capture the discussion, but if anything doesn’t look right to you please let me know. 

- Recap of relevant/interesting items and action items from AST. Parameter sets for default Argo-compliant profiles ([Issue #5 · OneArgo/ArgoTechCoP](https://github.com/OneArgo/ArgoTechCoP/issues/5)) are a priority, aim to have ready by next virtual meeting/for ADMT. 
- Discussion on TBT and the possibility of shipping CTDs without the TBT pill installed ([Issue #21 · OneArgo/ArgoTechCoP](https://github.com/OneArgo/ArgoTechCoP/issues/21)). Some groups, usually super-user groups, remove the TBT for pre-deployment sensor testing and then re-install before deployment. It would be convenient for these groups to receive floats with a CTD that never had the TBT installed, and then install it themselves following testing. This could not be a change to CTD supply in general, as many groups do not work with the CTD in this way pre-deployment. 
- There was also discussion of floats being deployed without TBT. While we may see some negative results in the short term (1-2 years), positive results will not be confirmed before 5-7 years. 
- Presentation on [Microcredentials](https://www.mtsociety.org/microcredentials#earning-microcredentials). At UW, students working in the float lab can earn microcredentials which can then be helpful in applying to positions in the field. We discussed that this could also be a good use case for ship techs and having confidence when shipping a float to a vessel to be deployed, someone on board is qualified to deploy the float successfully and safely. The rubrics can be found here: [Microcredential - Google Drive](https://drive.google.com/drive/folders/1ViABktdvVTH9ixkOPL-8SnmessUBsJiv).
